# 知乎去广告（ZhihuNoAds）· iOS 16 越狱 / 巨魔注入插件

> 一个**不需要你会编程**就能用的知乎去广告方案。
> 它能帮你拦掉：开屏广告、信息流广告、回答/文章页里的广告，以及"盐选会员"之类的推广弹窗。
> 同一个文件既能给**越狱**用，也能给**巨魔（TrollStore）**用。

---

## 一、这个东西是什么

知乎 App 里到处是广告。这个插件在知乎**启动的那一刻**就介入，从两个层面把广告挡掉：

1. **网络层拦截**：在广告请求到达服务器之前就拦下来，直接返回一个"空的广告"（所以你不会看到半屏空白，而是干脆没有那块内容）。
2. **界面兜底**：万一还有漏网的广告卡片或弹窗，插件会把它隐藏掉、或自动跳过开屏页。

它的特点：
- **不依赖越狱框架**（不依赖 CydiaSubstrate / ElleKit），纯靠系统自带的 Objective-C 运行时工作 → 所以同一个 `ZhihuNoAds.dylib` 文件，**越狱和巨魔都能用**。
- **不会误伤正常内容**：只针对"广告接口 / 广告类名 / 广告字段"下手，你关注的人、回答、文章都原样保留。
- **可开关、可统计**：在知乎里"摇一摇"手机，会弹出一个设置面板，可以逐项开关、查看拦截了多少广告、导出诊断日志。

## 二、你需要先准备什么

- 一部 **已越狱** 的 iPhone（iOS 14–16，例如 Dopamine 越狱），**或者** 已安装 **TrollStore**（巨魔）的 iPhone（iOS 14–16.6.1，视机型而定）。
- 手机上已经装好了**知乎 App**（从 App Store 装的正式版即可）。
- 一个 **GitHub 账号**（免费）。编译好的文件需要借助 GitHub 的免费服务器来生成，你自己的电脑不需要装任何开发工具。

> 如果你既没越狱也没装巨魔，那这个插件暂时用不了——它必须运行在越狱或巨魔环境里。
> 关于如何越狱 / 装巨魔，请自行搜索你机型和系统版本对应的教程（这部分不在本插件范围内）。

## 三、第一步：拿到编译好的文件（最关键）

你自己的电脑**不需要**装 Xcode，编译由 GitHub 的免费服务器完成。全程只需点几下鼠标。

### 1. 把本项目上传到你自己的 GitHub

因为本项目文件已经全部准备好，你只要把它们放进一个 GitHub 仓库即可：

- 打开 https://github.com/new ，新建一个仓库（名字随便，比如 `ZhihuNoAds`，**公开/私有都可以**，建议选 Public 以便 Actions 免费运行）。
- 在本项目的所有文件（见仓库根目录：`Sources/`、`layout/`、`Makefile`、`ZhihuNoAds.plist`、`.github/` 等）上传到你的新仓库。
  - 最简单：把本插件文件夹里的文件全部拖进 GitHub 网页的"上传文件"界面，一次性提交。

### 2. 开启并运行"自动编译"

- 进入你的仓库 → 顶部菜单 **Actions**（操作）。
- 第一次可能会看到" workflows 需要授权"，按提示 **Enable workflows（启用工作流）**。
- 点左边的 **"构建 ZhihuNoAds"** → 右上角 **Run workflow（运行工作流）** → 确认。
- 等待几分钟（通常 2–5 分钟），状态从黄点变绿勾，说明编译成功。

### 3. 下载成品

- 编译完成后，进到那次运行的页面，最下方 **Artifacts（产物）** 里有一个 **`ZhihuNoAds-成品`**。
- 点它下载，解压后你会得到两个文件：
  - **`ZhihuNoAds.dylib`** —— 给**巨魔**用（TrollFools 注入）。
  - **`ZhihuNoAds.deb`** —— 给**越狱**用（Sileo / Zebra 安装）。

> 之后每次我（或你）更新了代码并推送到仓库，Actions 都会自动重新编译，直接去下载最新 Artifacts 即可。

## 四、方式 A：巨魔（TrollStore）注入 —— 推荐给 iOS 16 用户

适合：已装 TrollStore 的用户。

1. 在手机上打开 **TrollFools**（巨魔注入工具）。
2. 在应用列表里找到 **知乎**，点进去。
3. 点"**注入 / Inject**"，选择你下载的 **`ZhihuNoAds.dylib`**。
4. 等待注入完成，回到主屏幕**彻底关闭知乎再重新打开**（上滑杀掉后台，再点开）。
5. 进知乎看看：开屏广告应该没了，信息流里也不再有广告卡片。

> 如果没生效：确认 dylib 确实是从 Actions 下载的最新版；确认知乎是 App Store 正式版；杀掉后台重新打开；摇一摇看设置面板能否弹出（能弹出说明插件已加载）。

---

## 五、方式 B：越狱安装（deb 包）

适合：已越狱（如 Dopamine）、装有 Sileo 或 Zebra 的用户。

1. 把下载的 **`ZhihuNoAds.deb`** 用 AirDrop / 文件 App / 网盘传到手机上。
2. 用 **Sileo** 或 **Zebra** 打开这个 deb 并安装（也可以在工作站的终端里用 `dpkg -i` 装，但手机端包管理器最省事）。
3. 安装完成后，**重启知乎**（杀掉后台重新打开）。 deb 里的脚本会自动结束正在运行的知乎。
4. 打开知乎验证效果。

> deb 会把 `ZhihuNoAds.dylib` 放到注入目录（`/Library/TweakInject/`），并带上过滤规则，确保**只**在知乎里生效，不会影响到别的 App。

## 六、怎么用设置面板（摇一摇）

打开知乎后，**摇一摇**手机，会弹出一个面板：

- **总开关**：一键启用 / 停用全部去广告功能。
- **功能开关**：开屏广告、信息流广告、回答/文章页、搜索热搜、会员弹窗、追踪上报、界面兜底，分别可开可关。
- **拦截统计**：显示各类广告各拦了多少次。
- **导出诊断日志**：把运行日志写到 App 的"文件"目录，方便排查问题。
- **恢复默认**：把所有开关还原。

> 如果摇一摇没反应，可以在"设置 → 辅助功能 → 触感/运动"里确认"摇动手势"已开启（系统级的那个开关）。

## 七、常见问题（FAQ）

**Q：我完全不懂编程，这些文件要怎么弄到 GitHub 上？**
A：不用写任何代码。你在电脑上把本文件夹里的文件，通过 GitHub 网页的"上传文件"按钮拖进去提交即可；剩下的"编译"点一下鼠标就自动完成（见第三节）。

**Q：编译要钱吗？**
A：GitHub Actions 对个人公开仓库免费，私有仓库也有免费额度，足够个人使用。

**Q：更新知乎 App 后插件会失效吗？**
A：一般不会。插件用的是"按广告特征拦截"的通用方式，不绑定某个具体版本。万一某次大更新后失效，回来重新跑一次 Actions 拿最新版即可（规则也会持续完善）。

**Q：会不会把我账号搞被封？**
A：本插件只在你手机本地拦截广告请求/隐藏广告视图，不修改知乎服务器数据、不上传任何东西、不模拟任何违规操作。它和你在浏览器里装广告拦截插件是同一性质。但任何修改客户端的行为都有理论上的政策风险，请自行权衡。

**Q：想卸载怎么办？**
A：巨魔：用 TrollFools 找到知乎 → 移除注入的 `ZhihuNoAds.dylib`。越狱：用 Sileo/Zebra 卸载 `com.zhna.zhihunoads` 这个包。

**Q：支持 iPad 吗？**
A：只要知乎的 bundle id 是 `com.zhihu.ios`（iPad 版通常也是这个），就支持。

## 八、目录结构（给想了解的人）

```
ZhihuNoAds/
├── Sources/            # 插件全部源码（纯 Objective-C，不依赖越狱框架/不链接 UIKit）
│   ├── ZHNAEntry.m        # 入口：判断是不是知乎、按顺序装好各道防线
│   ├── ZHNANetworkGuard.* # 网络层：拦截广告请求 + 清洗 JSON 里的广告字段
│   ├── ZHNAUIGuard.*      # 界面层：隐藏漏网的广告视图、跳过开屏
│   ├── ZHNARules.*        # 规则库：广告 URL、广告类名、广告字段名
│   ├── ZHNAJSONFilter.*   # JSON 递归清洗引擎
│   ├── ZHNAConfig.*       # 开关配置（存 NSUserDefaults）
│   ├── ZHNASettingsPanel.*# 摇一摇设置面板
│   ├── ZHNASwizzle.*      # 纯 runtime 方法替换
│   └── ZHNACommon.*       # 日志、统计、UIKit 影子协议等基础设施
├── layout/             # 打包 deb 用的目录结构
│   └── DEBIAN/             # control 包信息 + postinst 安装后脚本
├── tests/              # macOS 上可跑的本地自测（80 项全过）
├── Makefile            # 用 clang + iOS SDK 编译 dylib（无需 Theos）
├── ZhihuNoAds.plist    # 越狱注入的过滤规则（只在知乎里生效）
├── package_deb.sh      # 把 dylib 打包成 .deb
└── .github/workflows/build.yml  # 云端一键编译
```
